十一个常用指令与它们的修饰符

指令（Directive）是带 v- 前缀的特殊属性，本质是"在特定时机对 DOM 做特定操作"的声明。 本页把实验要求列出的指令逐个做成可交互示例，每块都标注了对应写法，方便对照抄用。

1

文本渲染：v-text / v-html / v-once / v-pre

插值表达式 vs 指令

v-text（纯文本）

v-html（解析标签）

v-once（只渲染一次）

{{ rawHtml }}

初始值固定，后续修改不再更新

v-pre（跳过编译）

{{ rawHtml }} —— 原样输出花括号
v-html 会执行字符串里的 HTML 与内联事件，永远不要渲染用户提交的内容。 在真实项目里这就是 XSS 漏洞入口，本页只演示机制，不做任何过滤。

DOM 实证： 用 document.querySelector 现场检查节点是否存在

v-if 区块

v-if 的节点（存在） 已被移出 DOM

v-show 区块

v-show 的节点（display 切换） 节点仍在，只是隐藏了

检测结果

#box-if 存在：{{ domProbe.hasIf }}

结论：需要频繁切换用 v-show（只改样式，开销小）； 条件很少变或需要彻底释放组件状态时用 v-if。同理，登录弹窗这种需要清空表单的，应该用 v-if。

3

列表渲染：v-for 的四种遍历对象

必须写 :key

数组 + 索引

  • {{ i }}. {{ item }}

v-for="(item, index) in list"

对象（值 / 键 / 索引）

  • {{ i }} {{ key }}：{{ val }}

v-for="(value, key, index) in obj"

数字（1 开始）

{{ n }}

v-for="n in 5" → 1,2,3,4,5

带条件过滤的列表

{{ f }}

只显示长度 > 3 的：bigFruits 由 computed 过滤得到，不在模板里写 v-if

:key 不是可有可无的装饰。Vue 用 key 判断"哪个节点是哪个"，缺少 key 时会退化为就地复用， 列表插入/排序/删除容易出现输入框串值、动画错位，控制台也会给出警告。 key 必须唯一且稳定，不要用数组下标（除非列表只追加）。
