阶段二：完成状态 / 行内编辑 / 分类统计

在基础版之上补齐四项功能：① 完成状态切换与删除线；② 编辑按钮 → 输入框； ③ 失焦或回车保存、Esc 取消；④ 未完成/已完成分类统计。 额外加了筛选、全选、清除已完成与 localStorage 持久化。

四项新增功能的实现要点

对照实验要求
1

完成状态

<input type="checkbox" v-model="todo.done">：v-model 直接绑定到对象属性上， 勾选即改数据；文字用 :class="{ done: todo.done }" 加删除线。 因为是同一个对象引用，改属性不需要替换数组，视图也会更新（响应式深层代理）。

2

点击"编辑" → p 变成 input

用一个 editingId 记录"当前正在编辑哪一条"，配合 v-if / v-else 在 <span> 与 <input> 之间切换； v-model="editingText" 时不要直接绑 todo.text，否则取消编辑无法还原。

3

失焦 / 回车保存，Esc 取消

@blur="saveEdit(todo)" 与 @keyup.enter="saveEdit(todo)" 共用一个保存方法； 保存时先 trim()，空内容视为放弃修改。 @keyup.esc="cancelEdit" 把 editingId 置空。 注意：回车保存后输入框被销毁也会触发 blur，所以保存方法要幂等。

4

分类统计

用 computed 从同一份 todos 派生出 { total, active, done }， 不额外维护计数器，避免"删了任务但统计没减"的经典 bug。 顶部进度条 = done / total，用 :style="{ width: percent + '%' }" 驱动。

展开查看增强版核心代码 
data() {
  return {
    todos: [],                 // { id, text, done }
    taskText: '',
    mode: 'all',               // all | active | done
    editingId: null,           // 正在编辑的任务 id
    editingText: ''            // 编辑时的临时副本
  }
},

computed: {
  // 分类统计：全部由 todos 派生，不存冗余状态
  stats() {
    const total = this.todos.length
    const done = this.todos.filter(t => t.done).length
    return { total, done, active: total - done }
  },
  percent() {
    return this.stats.total ? Math.round(this.stats.done / this.stats.total * 100) : 0
  },
  // 筛选后的可见列表（模板里 v-for 用它）
  visibleTodos() {
    if (this.mode === 'active') return this.todos.filter(t => !t.done)
    if (this.mode === 'done') return this.todos.filter(t => t.done)
    return this.todos
  },
  allDone() {
    return this.stats.total > 0 && this.stats.active === 0
  }
},

methods: {
  add() {
    const text = this.taskText.trim()
    if (!text) { this.$refs.taskInput.focus(); return }
    this.todos.push({ id: Date.now(), text, done: false })
    this.taskText = ''
  },
  del(id) {
    this.todos = this.todos.filter(t => t.id !== id)
  },
  startEdit(todo) {
    this.editingId = todo.id
    this.editingText = todo.text
    // DOM 更新后再聚焦，否则 input 还不存在
    this.$nextTick(() => {
      const el = this.$el.querySelector('.edit-input')
      el && el.focus()
    })
  },
  saveEdit(todo) {
    if (this.editingId !== todo.id) return      // 幂等：避免 blur 与 enter 重复执行
    const text = this.editingText.trim()
    if (text) todo.text = text                  // 空内容 = 放弃修改
    this.editingId = null
    this.editingText = ''
  },
  cancelEdit() {
    this.editingId = null
    this.editingText = ''
  }
},

watch: {
  // 任何改动都落盘，deep 才能监听到 todo.done 这种深层属性
  todos: {
    handler(list) { localStorage.setItem('lab5-todos', JSON.stringify(list)) },
    deep: true
  }
},

mounted() {
  const saved = localStorage.getItem('lab5-todos')
  if (saved) {
    try { this.todos = JSON.parse(saved) } catch (e) { console.warn('本地数据损坏', e) }
  }
}
