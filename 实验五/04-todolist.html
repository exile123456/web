阶段一：能加、能删、能统计

实验文档给出的最小版本：输入框回车添加、点击按钮删除、底部显示统计。 它把 v-for、v-model、v-on、v-if 四个指令串成了一个完整闭环，是理解"数据驱动视图"最省事的例子。

这里刻意去掉了"添加"按钮：input 在 form 里回车会触发表单 submit， 属于浏览器原生行为，用 @submit.prevent 接住即可，少一个控件、少一次点击。

四个指令如何串起来

本页 data / methods 对照
指令 / 选项 在本例中的职责
v-model 把输入框内容同步到 taskText，反向也可能（清空时输入框自动变空）
@submit.prevent 拦住表单默认的"提交并刷新页面"，改调 add()
v-for + :key 按数组长度生成 li；key 用稳定的 todo.id，删除时不会错位
@click 删除时传下标 index，由 del() 用 splice 移除
v-if / v-else 列表为空时显示空状态；全部完成时显示"🎉"标签
展开查看本页完整逻辑（与实验文档结构一致） 
<div id="app">
  <form @submit.prevent="add">
    <input v-model.trim="taskText" placeholder="输入任务内容，按回车添加">
  </form>

  <ul v-if="todos.length">
    <li v-for="(todo, index) in todos" :key="todo.id">
      <span @click="toggle(todo)">{{ todo.text }}</span>
      <button @click="del(index)">删除</button>
    </li>
  </ul>
  <div v-else>还没有任务…</div>

  <p>共 {{ todos.length }} 项任务</p>
</div>

<script>
const { createApp } = Vue
createApp({
  data() {
    return {
      todos: [],        // 待办任务列表数据
      taskText: ''      // input 输入框双向绑定的内容
    }
  },
  methods: {
    add() {
      const text = this.taskText.trim()
      if (!text) return                       // 输入内容为空则不入库
      this.todos.push({ id: Date.now(), text, done: false })
      this.taskText = ''                      // 清空输入框
    },
    del(index) {
      this.todos.splice(index, 1)             // 从数组中删除所点击的 li
    },
    toggle(todo) {
      todo.done = !todo.done                  // 基础版先留一个钩子，增强版会用到
    }
  }
}).mount('#app')
</script>
