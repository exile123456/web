实验三 · 2(1) 选项式 API 语法规则

data / methods / computed / watch / mounted

选项式 API（Options API）把所有能力按"选项"堆在一个对象里，交给 createApp() 后由 .mount('#app') 接管 DOM。 本页用五个可交互的小例子，逐个确认这五个选项各自负责什么。

所有交互都在浏览器内存中完成，刷新页面即恢复初始状态；右侧"数据探针"是调试面板， 直接打印组件当前的状态值，便于对照验收。
1

data 定义状态 · methods 定义动作

插值表达式 {{ }}

data() 必须返回一个新对象，Vue 会把它变成响应式数据； methods 里的函数通过 this 读写这些数据，改数据即改视图，不需要碰 DOM。

{{ count }}
数据探针 count = {{ count }}　double = {{ count * 2 }}（模板内表达式） clicks = {{ clicks }}　最近一次操作 = {{ lastAction }}

注意 {{ count * 2 }} 是写死在模板里的表达式，每次重新渲染都会重算； 而下面的 computed 会把结果缓存起来，只有依赖变了才重新求值。

2

computed 计算属性：带缓存的派生状态

依赖不变 → 不重算

computed · total

¥ {{ total }}
getter 实际求值次数：{{ computeCalls }}

methods · getTotal()

¥ {{ lastMethodResult }}
方法被调用次数：{{ methodCalls }}
反复点第二个按钮，computeCalls 不会增长 —— 这就是缓存。
为了把缓存"看得见"，本示例在 computed 里用 setTimeout 记录了一次调用次数。 这只是教学用的观察手段 —— 真实项目中不要 computed 里做副作用， computed 应该只负责"由已有状态算出新值"。
3

watch 侦听器：数据变化时执行副作用

watch / deep
watch 回调收到的新旧值 title 当前 = "{{ title }}" newTitle = "{{ watchState.newVal }}" oldTitle = "{{ watchState.oldVal }}" 触发次数 = {{ watchState.hits }} 次，最近一次 {{ watchState.at || '—' }} 字数 = {{ title.length }} 字 {{ title.length > 20 ? '（偏长了）' : '' }}

对象深层侦听（deep: true）

watch: { profile: { handler, deep: true } } —— 不开启 deep 时， 修改 profile.nickname 不会触发侦听，因为对象引用本身没变。 当前已触发 {{ profileHits }} 次。

4

生命周期钩子：mounted 之后才能安全操作 DOM

created → mounted → updated
挂载信息 挂载时刻 = {{ mountedAt }} 根节点高度 = {{ rootHeight }} px 说明 = 高度只有在 mounted 之后才读得到真实值

const { createApp } = Vue

createApp({
  // ① 状态：必须返回新对象，Vue 会做响应式代理
  data() {
    return {
      count: 0,
      price: 99,
      qty: 2,
      title: '',
      profile: { nickname: '陈燃', city: '重庆' },
      computeCalls: 0,
      methodCalls: 0,
      hookLog: []
    }
  },

  // ② 派生状态：有缓存，只在依赖变化时重新求值
  computed: {
    total() {
      // 调试用：异步登记一次求值，避免在 getter 里同步修改响应式数据
      setTimeout(() => { this.computeCalls++ }, 0)
      return this.price * this.qty
    }
  },

  // ③ 动作：由事件触发，每次调用都执行
  methods: {
    getTotal() {
      return this.price * this.qty
    },
    callMethod() {
      this.lastMethodResult = this.getTotal()
      this.methodCalls++
    }
  },

  // ④ 副作用：数据变化后执行（异步批处理，默认不等待 DOM 更新）
  watch: {
    title(newVal, oldVal) {
      this.watchState = { newVal, oldVal, hits: this.watchState.hits + 1, at: new Date().toLocaleTimeString() }
    },
    profile: {
      handler() { this.profileHits++ },
      deep: true          // 对象内部属性变化也要侦听
    }
  },

  // ⑤ 生命周期：此时 DOM 已挂载，可以读取尺寸
  mounted() {
    this.mountedAt = new Date().toLocaleTimeString()
    this.measure()
  }
}).mount('#app')
